# SuppMaterial-BiodivOysterAquacul
Scripts needed to perform the analyses for the manuscript by Givens et al, 2025

This workflow starts with the consensus sequences generated by the workflow outlined in the ONTbroadsp_eDNA pipeline (https://github.com/lauragivens/ONTbroadsp_eDNA/tree/main) on R9.4 sequencing runs.
